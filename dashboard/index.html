About the odds — read this before trusting the ranking

Smooth odds, assumed — not fitted. The board's odds fall with age: 0.55·exp(−age/1500) + 0.08. That is a survival-hazard framing, stated explicitly as an assumption: a single snapshot cannot estimate a survival hazard, because it carries no listing dates. The cross-sectional evidence points the other way — older protocols in this snapshot are more likely to already record a token — so the falling odds are a modelling choice, not a finding. The logit answers P(records a token | age); the board's odds answer the different question P(eventually lists | still no token at this age).

Coverage

The snapshot holds 758 protocols. 342 record no token; 198 of them can be priced and are ranked below, including all 40 watchlist protocols. The other 144 pre-token protocols are excluded by the watchlist rule (centralized exchanges, bridges, liquid staking and restaking, versioned or wrapped/staked products, exchange-named products). 128 traded protocols anchor the size curve.
